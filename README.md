## 📌 Featured Project

### 📊 Insurance Sales Performance Analytics Dashboard

**Project Repository:** [Insurance Sales Performance Analytics Dashboard](https://github.com/sairamkatam/Insurance-Sales-Performance-Analytics-Dashboard)

**Project Overview**

Developed an insurance sales performance dashboard to analyze sales targets, placed revenue, invoiced revenue, sales opportunities, and meeting activity at the branch level.

The project uses MySQL for data processing and KPI calculations, Excel for interactive dashboards, and Tableau for data visualization.

**Tools Used**
- SQL
- MySQL
- Microsoft Excel
- Tableau

**Key Features**
- Sales target analysis for new, cross-sell, and renewal business.
- Placed and invoiced revenue comparison.
- Target achievement percentage calculations.
- Sales opportunity pipeline analysis.
- Meeting activity by account executive and year.
- Interactive Excel dashboard with PivotTables and slicers.
- Validation of SQL results against Excel dashboard totals.

**Key Business Insights**

| Business Type | Target | Placed Revenue | Achievement | Invoiced Revenue |
|---|---:|---:|---:|---:|
| Cross-sell | 20.08M | 13.04M | 64.94% | 2.85M |
| New | 19.67M | 3.53M | 17.95% | 0.57M |
| Renewal | 12.32M | 18.51M | 150.23% | 8.24M |

**Project Highlights**
- Analyzed six Excel source files using MySQL.
- Used SQL aggregations and `UNION ALL` to combine brokerage and fee records.
- Analyzed 49 sales opportunities, including 44 open opportunities.
- Built interactive dashboards to support sales performance monitoring.
- Reconciled SQL calculations with Excel dashboard totals.

**Future Improvements**
- Correct and validate Tableau calculations and data relationships.
- Implement achievement percentages and conversion ratios in SQL.
- Classify invoices with missing income categories as "Unclassified."
- Investigate the gap between placed and invoiced revenue.
